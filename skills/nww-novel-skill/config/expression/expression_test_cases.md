# A组：应该检测（真实的表达模板重复）

Case A01
她心里七上八下，可面上没露，照常开门支锅。

Case A04

Case A06

Expected: TPL-B 通用角色反应

Case A07

Expected: TPL-B 通用角色反应

Case A08

Case A09

Expected: TPL-C 机械空间定位

Case A10

Case A11
可她心里那点不安，也跟烟火值一样，悄悄涨了起来。
Expected: TPL-A 内心强撑（可她心里X），CH1

Case A12

Case A13

Expected: TPL-A 内心强撑，CH1

Case A14
他施展《青云剑诀》，剑尖下压三寸，左手掐诀。
下一章他再次施展《青云剑诀》，剑尖下压三寸，左手掐诀。
Expected: CANON 招式名，NO ALERT（不进入VARIABLE重复）
