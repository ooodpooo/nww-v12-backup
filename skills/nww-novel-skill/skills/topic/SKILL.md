# nww-topic — 选题策划

新书启动第一步。从市场热点与读者预期出发，产出可选题材方向，供作者裁决后进入 `/nww-setup` 建书。

## 触发场景

想写小说不知道写什么 / 帮我选个题材 / 分析什么题材火 / 选题评估 / 想个金手指 / 现在什么网文题材好卖

## 输出（选题策划报告）

按 `nww-setup/references/agent-references/topic-options.md` 模板输出，**以下 8 个环节为必选，顺序不可跳过**：

1. **市场分析**：热点题材排行、目标题材市场表现、受众画像（注：AI 知识推理，非实时数据，建议结合实际平台榜单交叉验证）。
2. **发布平台确定**：从起点 / 番茄 / 知乎 / 刺猬猫 / 七猫 / 飞卢 / 晋江 / 纵横等平台中选定目标平台；输出平台适配说明——节奏密度、书名风格、简介类型、读者画像、内容雷点、变现模式与更新要求、**章节字数规范**（按平台官方建议给出参考区间，校准依据 `references/agent-references/platform-wordcount.md`）；同一题材在不同平台写法不同，必须用目标平台校准（参考 `genre-readers.md` 跨网站题材适配章节）。
3. **量级确定**：全书预估字数（短篇 <30万 / 中篇 30-100万 / 长篇 100-300万 / 超长篇 >300万）、卷数规划、更新频率（日更/隔日/周更）、日更字数目标、预计完结周期；量级直接影响细纲密度与卷纲拆分，必须在建书前锁定。
4. **文风确定**：语言风格定位（白描 / 华丽 / 冷硬 / 幽默 / 沉郁 / 轻快 / 市井 / 文气等）、叙事视角（第一人称 / 第三人称限制 / 第三人称全知）、句式节奏偏好（短句为主 / 长短交错 / 段落长度倾向）、对标文风参考（主对标书或作者文风）；产出 `设定/文风.md` 初稿，供 long-write Phase 4 与 deslop 调用。
5. **选题方案 3–5 个**：每个方案须标注「适配平台」「量级」「文风定位」，含核心概念、金手指设计（规则/限制/成长路径）、核心卖点、受众定位、爽点模式、开篇建议、竞争力评分。
6. **评估对比 + 推荐**：评分对比表 + 最终推荐与理由。
7. **创作执行建议**：开篇节奏、人设框架、主线设计、差异化竞争策略。
8. **风险提示**：政策/饱和/生命周期风险与应对。

> 选题输出不落盘中间 JSON；作者选定后，核心设定（金手指/代价系统/签名比喻）由 `/nww-setup` 写入 bible.json 字段；**平台 / 量级 / 文风** 分别写入 bible.json 的 `platform` / `scale` 字段与 `设定/文风.md`，供硬事实锚与一致性检查引用。

## 与既有参考文件的关系

- 题材框架速查：`nww-setup/references/agent-references/genre-catalog.md`
- 核心梗/金手指骨相：`nww-setup/references/agent-references/genre-core-mechanics.md`
- 命名：`nww-setup/references/agent-references/naming-library.md`
- 书名命名技法：`nww-setup/references/agent-references/naming-rules.md`（NR-003：身份型/冲突型/平台适配/3秒自检）
- 选题方案模板：`nww-setup/references/agent-references/topic-options.md`

## 边界

- 选题输出是**建议**，最终由作者裁决；不直接建书（建书走 `/nww-setup`）。
- 市场分析不伪造实时榜单数字；无实时数据时明确标注「AI 知识推理」。
