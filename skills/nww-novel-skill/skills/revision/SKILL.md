# nww-revision — 章节动机修订算子（vE1）

## 定位

- 生产位：**Stage 3 Revision 层**，独立子 skill，**零耦合**：不改 long-write 主链任何 Phase、不改任何现有脚本、不新增代码依赖。
- 适用范围：旧章 / 新章初稿的「动机显化」修复。**不是全文增强、不是新章脚手架、不是评分器。**
- 默认**不激活**：显式触发 `/nww-revision <目标章>`；或 `{BOOK}/.revision.enabled` 存在时，写章完成后仅**提示**是否过一遍（不强制进入主链，对齐 `.memory-pack.enabled` 先例）。

## 调用规则（E1 冻结，三条硬规则）

1. **诊断命中才局部修改**：行动跳跃 / 选择前压力缺失 / 选后代价未落地；全章三查无命中 → 不修订，直接输出「诊断零命中」退出。
2. **只增不删**：补选前压力（≤2 处）＋选后代价反馈（≤1 处）；**不删除原稿任何已落地的成本/代价表达**（E0 教训：误删成本段 → 选择合理性 -0.6）。
3. **补选择，不补解释**：增补回答「为什么必须选 / 为什么现在选」，不解释方法论、不推演全局政治后果。

## 呈现约束（主动必须通过）

| 呈现方式 | 示例（E1 已验证） |
|---|---|
| ✅ 行动 | 后槽牙结结实实咬了一下 / 没有回头 / 告假条压在案上没收回 |
| ✅ 决策（一句话决断） | 刀他自己递的 / 这份迟，他赔不起 |
| ✅ 后果承担 | 代价落在身体、物件、关系上 |
| ❌ **语言宣言**（φ2） | “这是我必须抓住的机会”式——角色告诉读者自己为什么这么做（ch5 实证副作用） |
| ❌ **策略推演独白**（φ1） | “不如趁查账前先说，否则就成认账”式——作者级政治逻辑塞给角色（ch3 实证需裁剪） |

## 硬性上限

- 单处增补 ≤2 句；单章增补 ≤3 处；禁止章内两处重复同一语义（ch3 教训：「漕账迟早翻明面」出现两次）。
- 增补位置：选前压力紧贴选择前 1-2 处；选后代价紧贴选择后 1 处。禁止全局盲插。

## 执行流程

### Step 1 · 备份（回滚点，必先）

```bash
{PYTHON} {SKILL}/../scripts/nww_backup.py --book {BOOK} --file {目标正文.md}
```

幂等：首份 `.backup/{name}.orig.md`（只读 0444），已有不覆盖。**未备份不动正文。**

### Step 2 · 诊断

输入：目标章正文 + 细纲 `{BOOK}/大纲/细纲_第{NNN}章.md` + `{BOOK}/追踪/_tracking-state.json` + `{BOOK}/bible.json`。

只做三查：
- 行动跳跃：关键选择的出现缺"为什么现在"的支撑？
- 选择前压力缺失：选择前一瞬没有"不选会怎样/选了收不回收"的锚？
- 选后代价未落地：选择后果没有落到身体/物件/关系上？

三查全无命中 → 输出「诊断零命中，不修订」，终止。

### Step 3 · 局部修

按调用规则 + 呈现约束 + 硬性上限局部增补。**产物存 `{BOOK}/实验_revision/正文/{name}.revision_vE1.md`**——试跑期不写生产正文路径（生产正文零触碰；授信后才允许写生产路径）。

### Step 4 · 确定性复跑（全部通过才可进入对比）

```bash
{PYTHON} {ROOT}/quality/detect_internal.py {修订版}            # I-A~I-H 全 PASS；I-G/I-H fail 硬阻断
node {SKILL}/../scripts/check-ai-patterns.js --check --fail-on=blocking {修订版}
{PYTHON} {SKILL}/../scripts/nww_ctl.py wordcount checkpoint --file {修订版} --target {细纲字数目标} --chapter {NNN}
```

复跑后自查 φ1/φ2（见呈现约束，命中即改写或作废）：
- φ1：新增若位于决策句前且以「不如/否则/与其…不如/迟早」起首 → 策略推演，改写为动作化或删除；
- φ2：新增若为「这份/这个机会/我必须」起首的陈述句 → 语言宣言，删除。

### Step 5 · 对比与授信

基线 vs 修订版，判定三项：选择更清晰？无解释负担增量？无字数越带？
- 全过 → 授信：允许该修订版进入生产正文（写生产路径前 Step 1 备份已备）。
- 任一项不过 → 回滚（见下）。

## 回滚动作（任一判定门 FAIL → 按序立即执行）

1. 删除 `{BOOK}/实验_revision/` 下对应修订产物；
2. 若已写生产路径：`cp .backup/{name}.orig.md {生产正文}` 覆盖恢复；
3. 删除 `{BOOK}/.revision.enabled`（若开过）；
4. 复跑 `I-A~I-G` 确认已净。

## 判定门（任一 FAIL → 立即回滚，不讨论）

| 门 | FAIL 条件 |
|---|---|
| 机械层 | I-G fail / check-ai-patterns blocking / 确定性脚本报错 |
| 字数 | 越用户字数带下限 / 增补 >3 处或单处 >2 句 / 章内语义重复 |
| φ 类 | φ1 / φ2 命中且未处置 |
| 对比 | 基线 vs 修订无提升，或出现语言宣言/策略推演/复盘词增量 |

## 边界

- 只处理「动机显化」；**不承诺提分、不处理结构问题、不替剧情把关**（结构/剧情走 prealign / 一致性 / 门禁体系）。
- ch3 类高密度权谋段：φ1 强制二次审查（E1 实证：此类增补须裁剪才能入生产）。
- 本 skill 不改任何现有文件；引用的脚本（nww_backup / detect_internal / check-ai-patterns / nww_ctl）均为既有工具。
- 实验期（授信前）不写生产正文；授信后的正式修订才写生产路径（此时 `.orig.md` 回滚点已就位）。
