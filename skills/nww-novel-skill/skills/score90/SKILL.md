# nww-score90 — 90分评分（卷/整本）

对一卷（或整本）输出可审计的 90 分制评分。**模型无关**：外部维度由运行本 skill 的 Agent 按方法论执行，内部证据由确定性脚本提供。完整规则见项目根 `quality/rubric_90score_v3.md`（第 0 节文件清单、第 2 节外部维度、第 3 节内部维度、第 4 节综合分、第 6 节 90 分底线）。`quality/` 位于项目根（`{ROOT}/quality/`，即 skill 包外一级），确定性脚本为 `{ROOT}/quality/detect_internal.py`。

## 前提

- 书项目在 `projects/{book}/`，含 `正文/`（长篇章）与 `追踪/`（状态）。
- 卷评分时机：写满一卷（或整本）后调用；单章质量由 long-write 的 Phase 4.5 写后门禁负责，本 skill 不做单章拦截。

## Step 1 · 跑内部确定性检测（I-A~I-H）

对卷内每章跑确定性检测，汇总全卷：

```bash
{PYTHON} {ROOT}/quality/detect_internal.py {BOOK}/正文/第*章*.md {BOOK}/正文/*/第*章*.md
```
正文按卷分目录的书，卷内章节用后一个 glob（`正文/{卷名}/第N章*.md`）收集；脚本接受任意文件参数。

记录：每章 I-A~I-H 的 status（pass/warning/info）+ 命中明细。这些是内部证据的硬数据。

## Step 2 · 外部维度评分（E0 + E1-E5，Agent 按方法论执行）

对卷/整本逐维度评分（0-100），**每条必须挂内部证据**（从 Step 1 结果或门禁判定中引用），无证据的维度视为无效评分：

- **E0 黄金三章 特审**（只评前三章的"链"）：G1 章1→章2 升级 / G2 章2→章3 落差 / G3 钩住→立住→可追 / G4 过渡自然 / G5 整体追读力。判死项（严重违背才触发）：主角身份不可逆颠倒、三章无任何追读理由（软钩子也算追读理由，不判死）。
- **E1 开篇即戏**：章首反常锚点（正文证据 + I-0 开头新鲜度）。
- **E2 设定绑定**：设定绑物/事/价/恐惧，零纯说明段（证据：设定一致性门禁）。
- **E3 节奏张力**：认知落差 + 章末钩子（证据：冲突推进/章末钩子/剧情循环门禁 + I-A）。
- **E4 爽点与成长动力**：阶段目标/成长动力（增长资产 或 悬念释放 或 认知升级任一）（证据：情绪曲线/认知落差门禁）。软钩子驱动不扣分。
- **E5 人物与对话**：声音+动作立人、对话双职能、金句锚（证据：对话框职能门禁）。

评分时先跑门禁 rubric（见 rubric 第 3.2 节），把 PASS/WARN/FAIL 与 S1-S4 严重度作为 E 维度证据引用。

## Step 3 · 综合分与底线判定

```
综合分 = 外部均值 × (1 - 内部扣分系数)
  外部均值 = ((E0特审分)×0.42 + (E1+E2+E3+E4+E5)/5×0.58)
  内部扣分系数 = 按 rubric 第 3.3 节扣分点清单累计（0~0.25）
  硬门槛：存在 S1 → 不通过；E0 严重违背 → 首三章不合格
```

**90 分底线判定**（rubric 第 6 节，全部满足才够 90 分档）：

| 底线 | 判据 |
|------|------|
| E1 | 前三屏有反常锚点 |
| E2 | 设定绑定物/事/价/恐惧，零纯说明段 |
| E3 | 章末有钩子 |
| E4 | 有阶段目标/成长动力（增长资产/悬念释放/认知升级任一） |
| E5 | 对话承担≥2职能 |

任一条不满足 → 掉出 90 分档。任一条 S1/判死 → 不通过。

## Step 4 · 输出评分报告

按以下结构输出（写入 `{BOOK}/评分报告_{卷号或整本}.md`）：

```
# {book} 第{N}卷 · 90分评分报告
- 综合分：{X.X}（外部 {Y} × (1-内部扣 {Z})）
- E0 黄金三章：{分}（G1-G5 各 pass/fail + 判死判定）
- E1-E5：每维 {分} + 证据引用
- 内部检测命中：I-A~I-H warning/info 列表
- 门禁：PASS/WARN/FAIL + S1-S4
- 90分底线：E1-E5 各 通过/未过
- 结论：达到 90 分档 / 未达（列出未达标项与修复建议）
```

**不达标 → 给修复建议并建议回改对应维度**（对大段落 AI 味/节奏问题建议过 Phase 4.5 门禁；对结构问题建议回细纲按写前对齐清单补）。
