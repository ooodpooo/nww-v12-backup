# 选题方案模板（topic-options）

供 `nww-topic` 选题策划时使用。每个选题方案须覆盖以下字段；评分统一 1–10 分（政策风险用 低/中/高 等级）。

## 市场分析（AI 知识推理，非实时数据）

> 市场分析基于 AI 对网文领域的知识推理，**非实时平台数据**，建议结合实际平台榜单交叉验证后再定稿。

- 当前热点题材排行
- 目标题材市场表现
- 受众画像与偏好

## 发布平台确定（必选）

- **目标平台**：起点 / 番茄 / 知乎 / 刺猬猫 / 七猫 / 飞卢 / 晋江 / 纵横 / 其他
- **平台适配说明**：
  - 节奏密度（慢热铺垫 / 快节奏直给 / 单元剧切换）
  - 书名风格（噱头吸量 / 意境逼格 / 身份反差 / 主线+爽点）
  - 简介类型（四段式成功 / 三段式行动 / 二段式悬疑 / 四段式失败）
  - 读者画像与付费习惯
  - 内容雷点与审核红线
  - 变现模式（订阅 / 免费广告 / 盐选 / IP 改编）与更新要求
- **平台校准依据**：参考 `genre-readers.md` 跨网站题材适配章节，用目标平台近期样本校准

## 量级确定（必选）

- **全书预估字数**：短篇 <30万 / 中篇 30-100万 / 长篇 100-300万 / 超长篇 >300万
- **卷数规划**：预计 N 卷，每卷约 N 万字
- **更新频率**：日更 / 隔日更 / 周更
- **日更字数目标**：N 字/天（单章目标按发布平台字数规范设定，见 `platform-wordcount.md`；如番茄单章 2000-2500，日更 N 章）
- **预计完结周期**：N 个月
- **量级对结构的影响**：细纲密度、卷纲拆分、支线容量、伏笔回收周期

## 文风确定（必选）

- **语言风格定位**：白描 / 华丽 / 冷硬 / 幽默 / 沉郁 / 轻快 / 市井 / 文气 / 其他
- **叙事视角**：第一人称 / 第三人称限制 / 第三人称全知
- **句式节奏偏好**：短句为主 / 长短交错 / 长句舒缓；段落长度倾向
- **对标文风参考**：主对标书或作者文风（注明书名/作者，仅作文风参考不抄内容）
- **文风锚点片段**：2-3 段示范文字，体现本书笔调（供 `设定/文风.md` 落盘）
- **文风禁忌**：明确本书不能出现的腔调（如"不能有解释腔"/"不能网络梗泛滥"/"不能文白夹杂"）

## 选题方案模板

### 选题：《书名》

- **适配平台**：{目标平台，如 番茄男频}
- **量级**：{全书字数 / 卷数 / 日更字数}
- **文风定位**：{语言风格 + 叙事视角，如 白描·第三人称限制}
- **核心概念**：一句话概括
- **金手指设计**：名称 + 规则 + 限制 + 成长路径
- **核心卖点**：3–5 个差异化优势
- **受众定位**：精准受众描述
- **爽点模式**：类型（打脸/升级/搞钱/恋爱/权谋…）+ 节奏 + 情绪曲线
- **开篇建议**：前三章情节规划
- **竞争力评分**：市场热度/竞争格局/受众规模/创作难度/变现潜力/政策风险 + 综合得分

## 评估维度说明

| 维度 | 含义 |
|---|---|
| 市场热度 | 题材当前热度与增长趋势 |
| 竞争格局 | 同类作品数量与头部集中度 |
| 受众规模 | 潜在读者群体大小与付费意愿 |
| 创作难度 | 设定复杂度、更新压力、专业知识要求 |
| 变现潜力 | IP 改编可能性、付费天花板、长尾效应 |
| 政策风险 | 题材敏感性、内容合规性 |
| 生命周期 | 题材持久度与可扩展性 |
