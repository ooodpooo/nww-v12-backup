# 章节标题规则（title-grading）

> 本文件是 NWW 项目章节标题的**唯一权威规则**。architect 拟章名、long-write 拼接标题行、quality 审查标题时，均以本文件为准。
> 原分散在 `nww-architect.md`（章名规则）、`outline-methods.md`（章节名策略）、`quality-dimension-standards.md`（格式一致度）中的标题相关内容已归档为引用指针，不再独立维护。
> 定位：创作时遵循的可执行规则，不是写完后才查的清单。

---

## 一、核心原则（一句话）

**标题 = 从本章找一个最让人好奇的画面/物件/台词/瞬间，把结果藏起来，只露出"让人想问然后呢"的那一半。**

去掉"发生了什么"，保留"让人好奇的画面"。

---

## 二、四种标题类型（取题时挑一个用）

| 类型 | 取法 | 示例 | 自带悬念 |
|---|---|---|---|
| **物件型** | 取本章一个重要物件，不说它的功能/来历/结局 | 半块匾 / 烫金的帖子 / 黑鼎 / 玉佩 | 高（谁的？为什么？） |
| **画面型** | 取本章一个具体画面，不说结果 | 青衫修士的眼泪 / 满街抽鼻子的修士 / 山门里的那双眼 | 中高（发生了什么？） |
| **台词型** | 取本章一句有意思的话，不说前因后果 | 喝一口，道心炸了 / 他说他没有师父 / 我道心松了半寸 | 高（谁说的？什么情况？） |
| **动作悬念型** | 动词+名词，让人想翻页看结果 | 一锅热油泼了贼 / 有个东西，扫过这铺子 / 执事喊他一声温道友 | 中高（然后呢？） |

**取题范围（硬绑定）**：只能从本章「核心事件 / 章首钩子 / 章末钩子 / 关键物件」中取，落在一个物、一句台词、一个动作上。禁抽象概念（命运/抉择/人心的裂缝）与情绪副词。

---

## 三、质量双测（拟完标题必过，两条都过才算合格）

| 测试 | 问法 | 通过标准 | 不通过表现 |
|---|---|---|---|
| **① 猜不出** | 读者只看标题，能不能猜出全章内容？ | 猜不出——有钩子，不剧透 | 看完标题就知道本章讲什么 = 剧透型，不合格 |
| **② 点灯感** | 读者读完本章回看标题，会不会有"哦原来指的是这个"的感觉？ | 有——标题落在本章某个具体物/动作/台词上，点题 | 读完发现标题跟本章没关系 = 飘，不合格 |

- 两条都过 = **S级标题**（可直接用）
- 只过① = 悬念够但飘（A-，需确认点题）
- 只过② = 点题但无聊（B，需换更有钩子的取法）
- 都不过 = **重取**

---

## 四、字数：软区间 2-10 字（不是硬约束）

| 区间 | 定位 | 说明 |
|---|---|---|
| 2-4字 | 舒适区（基因库头部作品占比约75%） | 物件型/画面型/动作型的天然长度 |
| 5-7字 | 正常区 | 台词型/画面型常用 |
| 8-10字 | 允许区 | 台词型/反差式标题天然需要长度，如"人和人的差距""竞争激烈和3级健体" |
| >10字 | 告警区 | 不是禁止，但需确认是否可以更凝练；台词型可豁免 |

**删掉旧规则的"2-7字硬约束"**——它会砍掉好标题。字数服务于吸引力，不是反过来。

---

## 五、类型轮换（防死板，卷内节奏）

1. **连续3章不得同型**——避免15章全是"物件名"的机械感。
2. **每卷物件型占比 20-30%**——物件型是最稳定的悬念载体（自带"这是什么"的好奇），但超过30%会显得单调；低于20%会失去稳定器。
3. **卷内节奏建议**（非硬规则，按剧情需要调整）：
   - 卷首（前3章）：优先台词型/动作悬念型——拉新读者，冲击力强
   - 卷中（中间章节）：物件型/画面型交替——稳定推进，物件埋伏笔
   - 卷末（最后3章）：台词型/动作悬念型——爆点收束，留卷尾钩
4. **卷间进化**（可选）：第二卷起可以有意识地 shift 主导类型（如第一卷偏物件，第二卷偏台词），让读者感受到标题风格的变化，但不强制。

## 六、题材适配（标题风格与题材绑定）

基于基因库5部头部作品实证：

| 题材 | 推荐主导类型 | 参考风格 | 示例 |
|---|---|---|---|
| 人文修仙·慢热 | 画面型+物件型，2字意象词为主 | 剑来式（惊蛰/碗水/稗草） | 墙根那半块焦匾 |
| 克苏鲁/悬疑/疯狂 | 物件型为主，2-3字纯名词 | 道诡异仙式（玉佩/黑鼎/黑太岁） | 烫金的帖子 |
| 古典修仙·大气 | 动作悬念型，4字对仗/诗意 | 太浩式（朝阳采气/寒月斩思） | 一锅热油泼了贼 |
| 现代/轻松/搞笑 | 场景/事件词+台词型，允许长标题 | 没钱式（面试/人和人的差距） | 喝一口，道心炸了 |
| 家族/史诗/群像 | 事件节点词，2-4字克制 | 玄鉴式（初入/结亲/杀人） | 执事喊他一声温道友 |

**跨题材缝合时**：主题材决定标题主导风格，辅题材只在个别章节提供变体。

---

## 七、负面清单（绝对禁止）

1. **禁抽象概念**：命运 / 抉择 / 人心的裂缝 / 觉醒 / 蜕变 / 成长——这些词放标题里等于没标题。
2. **禁剧透章尾爆点**：标题不能把本章最大反转直接说出来。
3. **禁震惊体**：惊！ / 万万没想到 / 竟然 / 居然——网文平台已审美疲劳。
4. **禁感叹号/省略号**：标题内不得出现 `！` `？`（反问句豁免，但需确认是台词型）`……` `。`
5. **禁说明性标题**：排队抢辣条 / 泡面香飘十里 / 会冒泡的甜水——这些是"本章内容摘要"，不是标题。改成画面式：青衫修士的眼泪 / 满街抽鼻子的修士 / 喝一口，道心炸了。
6. **禁与细纲/正文/文件名不一致**：四方一致（细纲首行 / 正文首行 / 文件名 / 逐章记录），不一致即 high。

---

## 八、取题流程（3步，拟章名时按此执行）

```
第1步：从本章细纲提取4个候选源
   → 核心事件里最反常的一个画面
   → 章首钩子的锚点（物/动作/台词）
   → 章末钩子的威胁载体（物/动作/台词）
   → 本章关键物件（契诃夫之枪级别的）

第2步：每个候选源按四种类型各拟1个标题（共4-16个候选）
   → 物件型：这个东西叫什么？
   → 画面型：这个画面最抓人的一半是什么？
   → 台词型：本章最有意思的半句话是什么？
   → 动作悬念型：动词+名词，结果藏起来

第3步：质量双测筛选
   → ① 猜不出全章？  ② 读完有"点灯感"？
   → 两条都过 → 进入类型轮换检查（连续3章不同型？本卷物件型占比？）
   → 通过 → 定稿，写入细纲首行
```

---

## 九、与细纲/正文的一致性

1. **细纲首行格式**：`# 细纲_第NNN章　章名：{标题}`（注意字段名是"章名"不是"书名"）
2. **正文首行格式**：`# 第N章　{标题}`（全角空格分隔章号与章名）
3. **文件名格式**：`第NNN章_{标题}.md`（标题中的标点保留，空格用下划线替代）
4. **逐章记录**：`追踪/逐章记录/第NNN章.md` 首行标注章名
5. 四方不一致 = high，必须修正后才能提交。

---

## 十、自检清单（拟完标题最后过一遍）

- [ ] 标题是从本章核心事件/钩子/关键物件取的，不是凭空想的？
- [ ] 去掉"发生了什么"，只保留"让人好奇的画面"？
- [ ] 双测①：只看标题猜不出全章？
- [ ] 双测②：读完本章回看有"点灯感"？
- [ ] 字数在2-10字软区间内（超过10字已确认是台词型/反差型需要）？
- [ ] 与前两章不同型（连续3章不同型）？
- [ ] 本卷物件型占比在20-30%区间？
- [ ] 无抽象概念/剧透/震惊体/感叹号省略号/说明性标题？
- [ ] 细纲首行/正文首行/文件名/逐章记录四方一致？

全部通过 → 标题定稿。
