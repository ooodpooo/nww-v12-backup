# 命名库（naming-library）

建书阶段命名参考：角色/门派/功法/地名/法宝的命名模板与素材库。
供 nww-architect（世界观/大纲）与 nww-character-designer（角色）在起名时读取。
原则：**先有定位后有名字**，名字必须服务角色/势力/世界观的功能与风格，不得为华丽而堆砌。

## 3. 名结构模板

| 结构 | 示例 | 适用 |
|---|---|---|
| 单姓+单名 | 陈默 / 苏晚 / 沈括 | 都市/悬疑/干练感 |
| 单姓+双名 | 林见深 / 程未央 / 顾长空 | 通用，古风/现言皆可 |
| 复姓+单名 | 慕容昭 / 南宫烈 / 东方既白 | 古言/仙侠世家 |
| 复姓+双名 | 司马南烛 / 上官云初 | 仙侠/权谋 |
| 名号/道号 | 一字真人 / 玄真子 / 无名客 | 仙侠（师门/境界相关） |
| 称号/代号 | "灰猫" / "静默" / K-731 | 科幻/谍战/网文味 |

> 关键配角与主角命名要区分度：主角名避免与高频配角撞字根；反派可用冷硬/谐音反讽。

## 4. 题材命名模板

### 4.1 仙侠/东方玄幻
- 道号：取性格/功法（剑痴·独孤 / 丹王·百草 / 刀奴·无咎）；法号多两字（了尘/净明/妄言）
- 功法名：动词+意象（《焚天诀》《渡厄经》《碎星拳》）；忌讳直白堆砌
- 境界名：炼气/筑基/金丹/元婴/化神/大乘/渡劫（或自造层级，须全书统一）

### 4.2 都市/职场/脑洞
- 网络感/反差：阿伟/老陈/李总；主角可带昵称反差（"铁蛋"配"灵气打工人"）
- 公司/组织：现实感+微变异（"玄门人力外包公司""天道集团"）
- 金手指名：口语化+系统感（"被剥削值系统""作死值面板"）

### 4.3 科幻/西幻/末世
- 音译规则：人名 2-3 音节（阿尔法/伊莱/珂朵莉）；地名用环境词（灰烬港/新艾泽拉斯）
- 编号体系：部队/实验体/飞船（"第七舰队""N-09"）
- 政权/组织：抽象+机构感（"星环议会""庇护所理事会"）

### 4.4 历史/古言
- 字辈/排行：名字按家族字辈排（"承""启""瑞"）；庶出/旁支可低一辈
- 官职/称号：与朝代官职体系匹配，不混用
- 女性名：取婉约字或按父辈期望（"宁""安""宜"）

## 5. 门派/势力命名模板

**前缀库 × 后缀库** 组合，避免生硬：

前缀：青云 / 龙门 / 无极 / 天机 / 万剑 / 逍遥 / 明镜 / 玄冥 / 太虚 / 归一 / 裂空 / 断岳 / 沧澜 / 焚天 / 紫霄 / 神机 / 罗刹 / 幽泉
后缀：门 / 派 / 宗 / 阁 / 盟 / 谷 / 宫 / 观 / 堂 / 会 / 教 / 帮 / 社 / 组 / 司 / 集团 / 事务所 / 世家

示例：
- 正道名门：青云门 / 太虚观 / 归一宗 / 明镜阁
- 魔道/反派：玄冥教 / 幽泉宫 / 罗刹堂 / 断岳盟
- 都市/现代：神机咨询 / 裂空安保 / 太虚数据 / 紫霄风投

> 势力名与势力定位强绑定：名门重"正/雅/稳"，反派重"暗/邪/狠"，中立重"机/器/利"。

## 6. 地名/功法/法宝命名模板

### 6.1 地名
- 中原正朔：洛阳/长安/金陵（史实地名须考证时代）
- 玄幻地名：五行+方位（东方青木洲 / 南离火域 / 西极金泽 / 北冥水渊 / 中土厚德城）
- 都市地名：虚构市名避开真实一线城市混淆（"临江市""云港市"）
- 门派驻地：山名+谷/峰/崖（"苍梧山·洗剑峰"）

### 6.2 功法
- 动宾式：焚天诀 / 渡厄经 / 淬体术 / 摄魂大法
- 意象式：枯荣心法 / 沧海一粟剑 / 无字天书
- 反讽式（本书风格）：《被剥削者自救手册》《加班燃魂诀》

### 6.3 法宝
- 器物+灵性：镇魂铃 / 缚妖索 / 量天尺 / 乾坤袋
- 现代变体：二手炼丹炉 / 官方报废功德碑 / 离职补偿合同（当作法宝）

## 7. 使用规则（全局）

1. **定位优先**：先写清楚角色/势力的功能与性格，再取名，不许先名后凑设定。
2. **风格一致**：全书命名风格统一（都偏古风或都偏现代），混搭须有设定理由。
3. **避撞**：避开知名作品主角名、历史名人与敏感谐音；同名角色须有区分（字/号/称号）。
4. **口顺**：姓+名连读顺口，避免生僻字滥用（生僻字用于配角/地名，主角名优先易懂易记）。
5. **叙事友好**：主角名 1-2 字为佳，长名在正文高频出现会拖节奏。
6. **与 bible.json 一致**：最终命名须写回 bible.json 的 characters/world 字段，供硬事实锚与一致性检查引用。
