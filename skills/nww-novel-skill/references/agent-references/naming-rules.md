# 命名规则库（naming-rules）

> **规则层**：管「怎么取名」——命名对象、适用题材、触发时机、正例/反例/毒点。
> 与 `naming-library.md`（素材层：姓氏/用字/模板）配合使用：规则层定方向，素材层取材。
>
> 触发对象：`nww-architect`（世界观/书名/金手指）、`nww-character-designer`（角色）、`topic`（书名选题）。
> 产物一律写回 `bible.json`（characters.name / identity 内嵌），供硬事实锚与一致性检查引用。

---

## 全局使用规则

1. **先定位后取名**：先写清角色功能 / 势力性质 / 核心卖点，再取名，禁止先名后凑设定。
2. **写回 bible**：最终命名写回 `bible.json` 的 characters / identity 字段（长名正文高频出现拖节奏，主角名 1-2 字为佳）。
3. **风格统一**：全书命名风格统一（都偏古风或都偏现代），混搭须有设定理由。
4. **避撞**：避开知名作品主角名、历史名人与高危谐音；同批角色名字需可区分（字根/声韵/字数至少一项不同）。
5. **一致性与校验**：命名后跑 `nww_name_check.py`（build/chapter/commit 三模式）复核重名、谐音与 bible 登记一致性。

## A级 · 建书必查

### NR-001 主角命名
- **触发**：`nww-character-designer` / `nww-architect`（建书阶段）
- **规则**：
  1. 避免现代网名感
  2. 名字需支持身份升级（不绑死初期身份标签，如「废柴」「赘婿」这类会被成长破掉的标签）
  3. 不用一次性爽文模板名
- **正例**：顾长夜 / 沈砚
- **反例**：龙傲天 / 叶凡123
- **毒点**：主角名像随机生成器；名字绑定「废柴/赘婿」等会被破的标签

### NR-002 配角命名
- **触发**：`nww-character-designer`
- **规则**：
  1. 与主角字根区分，避免同批角色共享相似字形/声韵（萧炎、萧寒、萧尘同场即毒点）
  2. 功能配角用有辨识度的名字（老吏、探子、话痨各自名字气质不同）
  3. 与主角名连读顺口，不产生谐音尴尬
- **正例**：郑直（老吏）
- **反例**：同批全员「凌X」式堆叠
- **毒点**：配角名与主角混读分不清；配角名字比主角还抢眼

### NR-003 书名命名
- **触发**：`topic` / `nww-architect`（选题建书）
- **规则**：
  - **身份型**：身份 + 场景 + 核心卖点（例《我在大唐开酒馆》）
  - **冲突型**：正常身份 + 异常能力（反差制造好奇）
  - **平台适配**：起点偏世界观/身份/能力；番茄偏冲突/爽点/结果
  - **自检**：书名 3 秒传达卖点；书名-简介-正文三位一体
- **正例**：《我在大唐开酒馆》/ 《退婚后我成了帝国战神》
- **反例**：无信息量纯意象名（《风过长街》）；书名与内容货不对板
- **毒点**：只堆辞藻无卖点；书名承诺的东西正文不兑现

### NR-004 金手指命名（webnovel 技法融合）
- **触发**：`nww-architect`（核心梗/金手指骨相）
- **规则**：功能 + 调性双轨；口语化 + 系统感；名字体现机制与限制
- **正例**：被剥削值系统 / 天机反噬
- **毒点**：宇宙最强全能xxx（过长且调性混乱）；名字与机制对不上

### NR-005 势力命名
- **触发**：`nww-architect`（世界观）
- **规则**：前缀×后缀组合（素材见 `naming-library.md`）；名与定位绑定（名门重正/雅/稳，反派重暗/邪/狠，中立重机/器/利）
- **正例**：青云门 / 玄冥教
- **毒点**：势力名与性质错位（魔教叫「仁德教」无理由）；同体系古今中外乱炖

### NR-006 功法/体系命名
- **触发**：`nww-architect`（力量体系）
- **规则**：动词+意象；同一体系语汇统一；低阶到高阶有递进感（同一母题链式递进，不是每阶换一套世界）
- **正例**：断潮步 / 焚骨诀
- **毒点**：只堆「天/神/龙/灭世」级大词；每阶命名断裂

## B级 · 写作期（首版只列规则，不配正反例）

> 触发：`nww-architect` / `nww-character-designer`（写作期新对象出现时）。

### NR-007 招式命名
名称至少体现流派、动作、元素、代价或传承之一，禁堆「灭世级」大词。

### NR-008 代号/绰号
代号像江湖口耳相传的标签（灰鸦/白手套/七号针），简短、易传播、带传闻感，非自封酷名。

### NR-009 职业序列
同一路线的称谓共享母题或职能词（见习巡夜人→守夜人→执灯官），升级像进阶而不是随机改名。

### NR-010 组织黑话
只点缀关键高频名词（钱/警察/同伴/敌人），禁整段对白堆满生造词；词形易懂易记，能映射群体文化。

### NR-011 卷名
服务阶段任务与卷级冲突（入宗试锋/帝都暗潮/北境决战），全书多卷保持同一命名语系与抽象层级。
