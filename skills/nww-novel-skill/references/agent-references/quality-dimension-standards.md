# 质量维度 → 设计创意撰写标准

> 本文件将「质量检查清单」的五维评分标准（quality-checklist.md）前置转化为创作时的设计/撰写标准，并新增「维度 6 · 叙事引擎」（依据基因库《好文章规则》——11 部起点头部作品写作基因提炼），补齐五维未覆盖的「吸引力/网文节奏」维度。
> 定位：创作时直接遵循的规则，不是写完后才查的清单。
> 使用方式：细纲创作时满足「设计标准」；正文写作时满足「撰写标准」；写每一段时用「达标自检」自我核对；全章写完后用「评分确认」一对一打分过门禁。
> 与 quality-checklist.md 的关系：一体两面——这里是「怎么写好」，checklist 是「写没写好」。

---

## 维度 1 · 核心一致度（动机 / 冲突 / 行动的一致性）

**核心问法**：这一章里，人物为什么要这么做？冲突为什么升级？前后是否自洽？

### 设计标准（细纲创作时强制满足）
1. 细纲必须写明本章主角的关键选择，以及这个选择背后的动机链条（被什么逼 / 想要什么 / 怕什么），动机不能凭空出现。
2. 细纲必须写清本章冲突的「变」：谁与谁的矛盾在什么节点升级、因什么事件升级，不允许「矛盾自己变深」。
3. 主角的关键行动必须与已建立的人设一致；若行动偏离人设，细纲里必须先写触发事件，不允许「突然这么干」。
4. 每条辅线（伏笔/关系线）在细纲里必须有推进或暂缓标记，不允许写了开头就忘。

### 撰写标准（正文写作时强制满足）
1. 写关键行动前，先在心里核对这个行动能不能从细纲动机推出；推不出，先补触发，再落笔。
2. 人物情绪的转变必须落在可见事件或可见动作上，不允许只用形容词跳变。
3. 冲突升级必须由具体情节推动（新证据、新压力、新选择），不允许用「气氛紧张了起来」这种空转句推。

### 达标自检（写时自我核对）
- [ ] 本章主角的选择，我能不能一句话说出动机？
- [ ] 本章冲突的升级点，是否有具体事件作为扳机？
- [ ] 有没有哪个行动是「作者想让他做」，而不是「这个人会做」？

### 评分确认（写完后打分，0-100）
- 80+：动机链条完整，冲突升级有事件扳机，无行动与人设矛盾
- 60-79：动机基本成立，但有 1 处需脑补的跳变
- 60 以下：存在动机突变无铺垫 / 核心冲突前后不一致 / 行动与性格矛盾，必须回改

## 维度 2 · 表层重写度（句式与措辞的原创性）

**核心问法**：这句话，是不是换个人也写得出来？是不是模板味？

### 设计标准（细纲创作时强制满足）
1. 细纲锁定的台词必须是「这句人物才说得出」的话（带人设、带处境），不允许锁定通用表态句。
2. 描述性情节（爽点、反转、钩子）在细纲里写清「怎么发生的」，不允许只写「发生了什么」。

### 撰写标准（正文写作时强制满足）
1. 禁用 AI 标志词与套路修辞（见 banned-words.md 与 anti-ai-writing.md），用具体描述替换。
2. 同一句式不连续重复；重复出现比喻时换喻体。
3. 描写要口语化 / 动作化：用动作落情绪，不用「他感到……」。动作化不是切成三五字短句串，叙述仍以逗号长句为主。
4. 对话带潜台词：人物说话要有「没说出口的那层」，不允许人人把想法说满。

### 达标自检（写时自我核对）
- [ ] 这句台词，换个角色说出来会不会违和？违和 = 没带人设。
- [ ] 这个比喻/句式，上一段用过没有？
- [ ] 有没有「他感到悲伤 / 命运在开玩笑 / 一切尽在不言中」这类可直接替换的模板句？

### 评分确认（写完后打分，0-100）
- 80+：句式措辞有辨识度，无 AI 标志词，比喻不重复
- 60-79：有个别模板句但不多
- 60 以下：大量 AI 标志词 / 同一句式重复 / 辞藻堆砌，必须去 AI 味

## 维度 3 · 格式一致度（段落节奏与格式）

**核心问法**：读起来卡不卡？信息差（读者需特别注意的提示）是否被清楚标记？格式是否统一？

> 校准说明：经 11 部起点头部作品对照（基因库），「内心独白用「」」硬规与头部生态 100% 冲突（头部三种主流做法：无标记思维流 / 内心与对话共用引号 / 吐槽前缀式），故降为可选；「段落必须按镜头断」与剑来等说书体长段冲突，放宽为「节奏可控」。唯一保留的标点约定是【】信息差提示——头部系统流（1984 等）已验证该符号零歧义，读者认知为「面板/提示」。

### 设计标准（细纲创作时强制满足）
1. 细纲必须写明「字数目标 + 字数口径」，正文字数围绕目标写，不是写多少算多少。
2. 细纲按情节点序列给出场景/镜头规划，正文按剧情需要自然分段，不允许机械按字数切段。

### 撰写标准（正文写作时强制满足）
1. 段落节奏可控：段内不机械、不主语过密；镜头可长可短，长段（说书体/信息块）只要读感绵密不卡即可，不强制镜头粒度。
2. 对话独立成行；标点整体从简，不做硬性约束——内心独白与对话是否用不同符号不再强制（头部靠上下文自然区分）。唯一保留约定：信息差提示（系统面板 / 关键情报 / 读者需特别注意的提示信息）用【】标记，全篇统一。
3. 开头结尾格式统一：正文首行为 `# 第N章 章名` 标题行（章名创作的唯一权威规则见 `title-grading.md`——核心原则、四种类型、质量双测、字数软区间、类型轮换、题材适配、负面清单、取题流程、四方一致性；章名必须与细纲首行一致），首行之后不写标题行、不写章节元信息；开头无缝接上一章动作/台词/现场，结尾落在变化上。
4. 目标字数控制：写作中逐段对照剩余区间，逼近/超出上限收敛，明显低于下限补足；绝不越过用户带（±15%）。

### 达标自检（写时自我核对）
- [ ] 这段读起来卡不卡？有没有机械切段或主语过密？
- [ ] 需要读者特别注意的信息差提示，用【】标了吗？全篇符号统一吗？
- [ ] 当前累计字数距目标还剩多少？超了没有？

### 评分确认（写完后打分，0-100）
- 80+：段落节奏自然，信息差标记清晰统一，字数在用户带内
- 60-79：个别段落略卡，或标点轻微不统一，或字数偏出但可用
- 60 以下：机械切段 / 主语过密 / 信息差无标记或混乱 / 字数大幅偏离目标（high 级问题），必须回改

## 维度 4 · 可读性（啰嗦 / AI 腔 / 空泛）

**核心问法**：读起来累不累？有没有能删的段落？

### 设计标准（细纲创作时强制满足）
1. 细纲每个情节点必须有「新信息」：要么推进事件，要么深化人物，要么改变关系/认知。写不出新信息的情节点直接删。
2. 细纲写明本章「不写什么」：不展开的部分、不解释的设定，避免正文失控铺陈。

### 撰写标准（正文写作时强制满足）
1. 无空泛总结（「他终于明白了」→ 用行动/发现代替）；无情绪标签（「他很难过」→ 写行为表现）。
2. 无连续多段同一情绪；心理描写不空转（重复读者已知信息 = 空转，压缩；带新信息/决断/转折的独白保留）。
3. 信息跟着冲突走，不单独写设定说明段；一章新概念不超 3 个。
4. 每段能删则删：删掉无损剧情推进的流程细节 = 水。

### 达标自检（写时自我核对）
- [ ] 这一段的「新信息」是什么？答不出 = 删。
- [ ] 有没有连续两段在讲同一个情绪？
- [ ] 有没有「主角内心重复读者已经知道的事」？

### 评分确认（写完后打分，0-100）
- 80+：信息密度高，无 AI 腔，无可删段落
- 60-79：个别空泛句 / 一两处空转
- 60 以下：啰嗦、空泛总结、套路修辞多，必须压缩改写

## 维度 5 · 逻辑连贯（设定 / 时间线 / 因果链）

**核心问法**：前后对得上吗？设定、时间线、因果有没有断？

### 设计标准（细纲创作时强制满足）
1. 细纲情节点序列必须构成完整因果链：证据 → 推断 → 行动 → 后果，不允许缺环。
2. 细纲写明时间线（故事内过了多久），正文推进不能跳漏或自相矛盾。
3. 涉及设定（境界/代价/伏笔状态）时，细纲直接引 bible.json / 角色状态 / 上下文，不靠记忆。

### 撰写标准（正文写作时强制满足）
1. 写前读上下文与硬事实锚（bible.json + 角色状态 + 上一章结尾），承接状态一律以锚为准。
2. 时间推进用角色可感知的锚（日头/灯/夜色/季节），不写「三日后」这种空转时间词（除非有戏剧作用）。
3. 因果链不省略过渡：从 A 到 B 的推理步骤要能对账，不允许「脑子一算」出结论。
4. 设定冲突即停：发现与已建立设定矛盾，先查锚再落笔，不硬写。

### 达标自检（写时自我核对）
- [ ] 本章的事件顺序，能不能构成一条完整因果链？
- [ ] 故事内时间轴，和上一章结尾/细纲对得上吗？
- [ ] 有没有用到设定，却没用锚核对？

### 评分确认（写完后打分，0-100）
- 80+：因果链完整，时间线清晰，无设定冲突
- 60-79：有 1 处需脑补的过渡或轻微时间模糊
- 60 以下：设定前后矛盾 / 时间线错误 / 因果链断裂（critical/high 级），必须修正

## 维度 6 · 叙事引擎（网文节奏 / 吸引力）

**核心问法**：读者会不会被开头勾住？信息是不是一层一层揭？爽点是不是即时落地？设定是不是「被看见」而非「被告知」？

> 依据：基因库《好文章规则》——11 部起点头部作品（诡秘之主/剑来/道诡异仙/青山/玄鉴仙族/赤心巡天/没钱修什么仙/剑烛大荒/捞尸人/1984川菜馆/太浩）写作基因提炼。此维度专门治「叙事方式不向网文节奏靠拢」——静态开篇、对话不承载信息、无认知落差、设定倾倒。

### 设计标准（细纲创作时强制满足）
1. 细纲写明「章首钩子」：前三屏必须抛一个反常锚点（感官悬疑 / 民俗动作 / 身份错位 / 奇观狂言）让读者陷进去；设定说明永远排在悬念之后。
2. 细纲每个情节点标注「认知落差」：主角「以为占了便宜 → 下一秒发现是劣势」。落差 = 追读动力；无落差的情节点 = 平，删或改。
3. 细纲写明「章末钩子」：结尾落在新的疑问 / 危机 / 变化上，不总结。
4. 细纲标注「爽点位置」：每个世界规则绑定「主角怕失去什么」（代价/卡关/焦虑）；爽点短周期、高频、可兑现，不攒到大结局；主角要有一条「看得见数字、在增长」的资产（战力/存款/口碑/境界）。
5. 细纲写出每个主要角色的「标志性台词 + 反复动作」锚，一人一个，开篇前就定。

### 撰写标准（正文写作时强制满足）
1. 开篇即戏：首段就是动作 / 台词 / 现场，反常锚点先行；设定说明永远排在悬念之后。
2. 世界观 Show, don't tell：每一条设定绑定「主角看见的物 / 做的事 / 付的价」才放出；零纯说明段，把世界当博物馆陈列，让读者自己捡到规则。
3. 人物用「声音 + 动作」立人：标志性口吻 + 反复动作，形容词越少越好；不靠作者旁白介绍人设。
4. 对话承担双重职能：同时露性格 + 推剧情 + 藏设定/关系；闲聊即 info-dump 的最佳容器（借师徒逗弄、分家产讲体系）。
5. 信息克制释放：一次只给烧脑的量；每揭一层，就推翻一层主角以为的优势。
6. 感官描写模型：代理反应 + 二字感官词串 + 质感对比 + 身体定位；写感受让配角当放大镜（可信十倍），不用作者自夸。
7. 文风：越离谱的设定越用最日常的腔调抛出（现代脑/方言消解奇观）；每章至少一句短、可摘抄、承载文眼的金句。

### 达标自检（写时自我核对）
- [ ] 前三屏有没有反常锚点？还是设定说明书？
- [ ] 这一段设定，绑定了「物/事/价/主角恐惧」吗？
- [ ] 每个出场角色，能不能被一句标志性台词或一个动作认出？
- [ ] 主角有没有「以为占便宜 → 发现劣势」的落差？
- [ ] 章末有没有钩子？
- [ ] 这句对话，同时推进了剧情 + 露了人设 + 藏了设定吗？
- [ ] 有没有一句可摘抄的金句当文眼？

### 评分确认（写完后打分，0-100）
- 80+：开篇即戏 + 设定绑定物事价 + 对话双职能 + 认知落差 + 章末钩子 + 金句锚，六项全过
- 60-79：开篇略静，或设定有 1-2 处纯说明段，或对话单职能，或钩子偏弱
- 60 以下：静态开篇 / 设定倾倒 / 对话不承载信息 / 无认知落差 / 无章末钩子，必须按对应规则回改

## 六维总分判定（写完后）

| 结果 | 判定 | 动作 |
|------|------|------|
| 六维均 ≥ 80 | 达标 | 进入提交流程 |
| 任一维 60-79 | 精修 | 对低分维执行对应修复（见 quality-checklist 精修策略） |
| 任一维 < 60 | 回改 | 定位该维问题段，重写后再评分，不允许带病提交 |

## 使用原则

1. **这不是死模板**：以上是方向/职责/任务目标，不是逐句执行的模板。允许根据作者需求换话风，但不得偏离各维度的职责目标。
2. **创作时用，写完才评**：设计标准/撰写标准/达标自检在创作过程中遵循；评分确认在写完后进行，两者分开，不互相污染。
3. **读者第一**：任何维度冲突时，优先考虑整体节奏感和吸引力（读者视角），避免局部打磨损伤整体。
4. **低风险接入**：本文件为独立参考文档，与现有流水线零耦合；验证有效后再考虑接入核心链路。
