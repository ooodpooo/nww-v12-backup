# NWW-V12 产品说明文档（PRODUCT）

> 产品：`nww-novel-skill` —— NWW-V12 网文生成总控 skill 包。
> 形态：Claude Code / OpenCode / Codex 插件式 skill（WorkBuddy 亦可直读 SKILL.md）。
> 版本：1.2.0。最后更新：2026-09-09（v1.2.0：细纲「本章目标」统率字段收编收益兑现/章尾钩子 + 节拍目标可验收规则 + 铺陈删除测试；v1.1.0：I-I 细纲承诺兑现度审稿维度）

---

## 1. 这是什么

NWW-V12 是一套**网文长篇小说生成与质量保障**的 skill 包。它把"写千章不崩 + 产文去 AI 味 + 90 分评分"的方法论，封装为可被 AI 编码运行时加载的插件：你用自然语言下达意图（开书、写章、去 AI 味、审一致性、评分），运行时宿主 LLM 按本包方法论驱动写作，**所有连续性/命名/质量护栏由确定性脚本与 hooks 兜底**。

一句话定位：**模型当写手，确定性脚本当编辑与门禁；写手可以换，护栏不动。**

---

## 2. 解决什么问题

| 痛点 | 本包的回答 |
|---|---|
| 长篇小说写到后期人设崩、时间线乱、伏笔断 | 千章不崩子系统：追踪事务（单一权威状态）+ 一致性只读审查 + 写前/写后门禁 |
| AI 写出来的网文"太 AI"（圆滑、工整、解释腔） | 产文质量子系统：去 AI 味七门禁 + 三遍法 + 退化指纹检测 |
| 成稿基础分低、写完大改 | 写前对齐（prealign）：动笔前用 90 分尺查结构层缺口，缺则回细纲补 |
| 换模型/换运行时就重做整套 | 纯 skill 模式、模型无关：不绑定任何模型客户端，Claude/OpenCode/Codex 通用 |

| 写一章 | `/nww-long-write`、/写章 | 硬事实锚 + 必种件兜底 + 机械层 + 去 AI 味 + 一致性 + 追踪提交 |
| 去 AI 味 | `/nww-deslop`、/去AI味 | 七门禁 + 三遍法 + 3 个确定性脚本 |
| 一致性审查 | `/nww-consistency`、/一致性 | 只读 S1–S4 冲突报告（设定/时间线/伏笔/角色属性） |
| 90 分评分 | `/nww-score90`、/评分 | 卷/整本综合分 + 90 分底线判定（模型无关） |
| 承诺兑现验收 | 写章审稿闭环内嵌（I-I 维度） | 对照细纲节拍/收益/钩子/纪律逐条验收正文兑现情况，未兑现项挂正文证据，I-I<70 分回细纲补结构 |
| 章节动机修订 | `/nww-revision`、/修订XX章（默认不激活，显式触发） | 诊断"行动跳跃/选前压力/选后代价"，只增不删局部修订 |
| 叙事节奏计划 | `/nww-rhythm`、/节奏计划（.nrl.enabled 时写章内嵌） | 跨章动力规划 + 单章节奏中间表示 |
| 扫榜与选题决策 | `/nww-scan`、/扫榜 | 平台榜单采集（起点/番茄/七猫/晋江/刺猬猫）→ 扫榜报告 → `选题决策.md`（能爆的原因先当假设，标待拆文验证） |

## 4. 典型使用流程

```
1. /nww-scan       想写什么 → 扫榜报告 + 选题决策.md（能爆原因先当假设）
2. /nww-analyze    验证假设 → 拆对标书 → 拆文库/{书名}/（自动回填选题决策）
3. /nww-topic      (可选) 选题深度策划 → 题材收敛
4. /nww-setup      选定题材 → 建书布局 + 部署门禁
5. /nww-prealign   写每章前 → 结构层对齐（钩子/绑定/落差/卡点）
6. /nww-long-write 写章 → 硬事实锚（可选对标锚）+ 机械层 + 去AI味 + 一致性 + 追踪提交
7. /nww-deslop     旧正文 → 批量去 AI 味（可选）
8. /nww-consistency 阶段性 → 一致性审查（只读）
9. /nww-score90    写满一卷 → 90 分评分与底线判定
10. /nww-revision   某章动机突兀 → 局部修订（显式触发）
```

## 5. 产品特性

- **千章不崩**：权威状态文件 + 派生视图校验 + 写前阻断，模型不参与连续性保证。
- **去 AI 味**：七门禁 + 三遍法 + 退化指纹检测，模型只改写、判定走确定性层。
- **模型无关 / 运行时无关**：不 import 任何模型客户端；Claude / OpenCode / Codex 通用，缺失 custom agent 时降级 solo 并报告。
- **fail-closed 护栏**：机械层修复失败宁可丢泄漏末段/拦下写作，也不依赖模型重生成。
- **可审计**：追踪事务、评分内部证据、一致性报告均为确定性产出，可复盘。
- **市场与对标（可选旁路）**：扫榜（`/nww-scan`）→ 拆文（`/nww-analyze`）→ 对标锚（`.benchmark.enabled` 时写章召回）。默认关闭，不改变现有写章行为。

## 8. 快速开始（对使用者）

1. 在 Claude Code / OpenCode / Codex 加载本插件（`skills/nww-novel-skill/`）。
2. 新书：`/nww-topic` → `/nww-setup`。
3. 写章：`/nww-long-write`（写前自动 prealign；写后自动过机械层 + 去 AI 味 + 一致性 + 追踪提交）。
4. 审与评：`/nww-consistency`、`/nww-score90`。
